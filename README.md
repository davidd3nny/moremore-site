# More&More: сайт ресторана

Одна страница: меню кухни и бара на трёх языках (AZ, RU, EN), афиша событий со всплывающим баннером, часы работы, бронь через WhatsApp.
Сайт собирается сам: Вы меняете текстовые файлы в папке `content/`, а GitHub через минуту-две публикует новую версию.

## Что где лежит

| Папка или файл | Что внутри | Кто меняет |
|---|---|---|
| `content/menu.toml` | всё меню: разделы, блюда, цены, бар | Вы, при изменении меню |
| `content/afisha.toml` | события и всплывающий баннер | Вы, каждую неделю |
| `content/venue.toml` | телефон, адрес, часы, ссылки, режим «черновик» | редко |
| `afisha/` | картинки для афиши (посты, сторис) | Вы, вместе с событием |
| `src/` | вёрстка и стили | только при доработке дизайна |
| `assets/` | шрифты и логотип | не трогать |
| `build.py` | сборщик сайта | не трогать |
| `.github/workflows/deploy.yml` | робот, который собирает и публикует сайт | не трогать |

## Первый запуск (один раз)

Репозиторий: `davidd3nny/moremore-site` (Public: на бесплатном плане GitHub Pages работает только с публичными).

1. Откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
2. Откройте вкладку **Actions**. Если первый запуск «Сайт» красный (он успел начаться до шага 1), откройте его и нажмите **Re-run all jobs**.
3. Через 1–2 минуты сайт откроется по адресу `https://davidd3nny.github.io/moremore-site/`.

## Поменять меню

1. Откройте `content/menu.toml` на github.com и нажмите карандаш (Edit). С телефона тоже можно.
2. Найдите блюдо и поменяйте название или цену. Формат строки:
   `["Название AZ | Название RU | Name EN", цена],`
3. Нажмите **Commit changes**. Через 1–2 минуты сайт обновится.

Цена: число (`15`) или текст в кавычках (`"16 / 14"`). Новое блюдо: скопируйте соседнюю строку целиком, с запятой в конце.

## Добавить событие и баннер

1. Загрузите картинку в папку `afisha/` (кнопка **Add file → Upload files**). Подойдёт пост или сторис из Instagram в JPG или PNG. Сайт сам уменьшит её.
2. Откройте `content/afisha.toml`, скопируйте блок `[[event]]` и поменяйте поля. Пример:

```toml
[[event]]
id = "karaoke-17-okt"
from = "2026-10-13"
to = "2026-10-17"
image = "karaoke.jpg"
title = "Karaoke gecəsi | Караоке-вечер | Karaoke night"
when = "Cümə, 17 oktyabr · 21:00 | Пятница, 17 октября · 21:00 | Friday, 17 October · 21:00"
text = "Ən sevdiyiniz mahnılar və dəniz mətbəxi. | Любимые песни и морская кухня. | Favourite songs and seafood."
button = "book"
popup = true
```

3. **Commit changes**. Баннер всплывёт у каждого гостя при входе на сайт с `from` по `to` включительно, а после `to` исчезнет сам.

Как ведёт себя баннер:
- всплывает через полсекунды после открытия сайта;
- закрывается крестиком, тапом мимо окна и клавишей Esc;
- всплывает при каждом открытии сайта; чтобы показывать его гостю раз в день, поставьте в начале `content/afisha.toml` `popup_repeat = "daily"`;
- все текущие события видны в блоке «Афиша» под первым экраном;
- если событий несколько, всплывает первое по списку в файле.

Пример `primer` в файле нужен только для показа владельцу. Когда появится первое настоящее событие, удалите блок `primer` и картинку `afisha/primer.jpg`.

## Часы, телефон, ссылки

Всё в `content/venue.toml`. Часы пишутся как `["12:00", "00:00"]`, ночные как есть: `["12:00", "04:00"]`.

## Когда сайт станет настоящим

1. В `content/venue.toml` поставьте `draft = false`: исчезнет метка «Концепт · черновик», сайт откроется для поисковиков.
2. Подключите домен `moremore.az` (ниже).

## Подключить домен moremore.az

Нужен доступ к DNS домена: логин в панель регистратора или человек, который добавит записи.

1. GitHub: аватар → **Settings → Pages → Add a domain** → `moremore.az`. GitHub покажет TXT-запись для подтверждения. Добавьте её в DNS и нажмите **Verify**.
2. Репозиторий: **Settings → Pages → Custom domain** → `moremore.az` → **Save**.
3. В DNS домена:

| Тип | Имя | Значение |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| AAAA | @ | 2606:50c0:8000::153 |
| AAAA | @ | 2606:50c0:8001::153 |
| AAAA | @ | 2606:50c0:8002::153 |
| AAAA | @ | 2606:50c0:8003::153 |
| CNAME | www | davidd3nny.github.io |

4. Старые A-записи сайта удалите. Записи почты (MX) и прочие не трогайте.
5. Подождите (бывает до 24 часов) и включите **Enforce HTTPS** в Settings → Pages.

Записи со звёздочкой (`*.moremore.az`) не создавайте: GitHub предупреждает, что это открывает домен для захвата.

## Собрать сайт на своём компьютере

```bash
pip3 install --user pillow tomli
python3 build.py
open dist/index.html
```

Подойдёт Python, который уже есть на Mac (3.9 и новее). Можно указать дату, чтобы проверить афишу: `python3 build.py 2026-10-17`.
В браузере для проверки работают параметры: `?lang=ru`, `?today=2026-10-17` (какой день показывать), `?nopromo` (без баннера).

## Если что-то пошло не так

Если в файле ошибка (пропала кавычка или запятая), робот во вкладке **Actions** станет красным, а на сайте останется прошлая версия. Откройте упавший запуск: в шаге «Собрать сайт» будет написано по-русски, в каком файле и в какой строке ошибка.

GitHub отключает ежедневный запуск, если в репозитории 60 дней не было правок. Тогда в **Actions** нажмите **Enable workflow**.
